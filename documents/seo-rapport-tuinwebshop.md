| **graszaad zandgrond** | Bijna geen gespecialiseerde pagina's; lokale hoek | Dedicated landingpage + blog |
| **graszaad kleigrond** | Idem — bodemtype pagina's bestaan amper | Dedicated landingpage + blog |
| **lege slanghaspel** | Alleen kabelshop.nl heeft een gefocuste pagina | Dedicated landingpage |
| **kabelhaspel buiten waterdicht** | Geen gespecialiseerde shops hiervoor | Dedicated landingpage |
| **kabelhaspel camping** | Niemand target dit specifiek | Blog + productpagina |
| **meststrooier gazon** | Weinig niche-webshops | Landingpage |
| **gazon beluchter** | Weinig dedicated shops | Landingpage |
| **graszaad sportveld** | Vooral B2B, weinig consumentengerichte content | Landingpage (B2B + B2C) |
| **gazonmest herfst** | Seizoensgevoelig, weinig dedicated pagina's | Landingpage + seizoenscontent |

### 6.2 Concurrentie-Zwaktes

| Concurrent | Zwakte | Jouw kans |
|------------|--------|-----------|
| **graszaaddirect.nl** | Alleen graszaad, geen haspels/gereedschap | Cross-sell: "alles voor je gazon op 1 plek" |
| **graszaadxl.nl** | Alleen Barenbrug-producten | Multi-merk aanbod |
| **toolnation.nl** | Technisch/professioneel gericht, geen tuin-focus | Tuin-specifieke haspels |
| **bol.com** | Generiek, geen advies/expertise | Specialistisch advies, keuzehulp |
| **Alle concurrenten** | Niemand combineert haspels + graszaad + tuinbenodigd. | Unieke niche-positionering |
| **Alle concurrenten** | Geen lokale focus op Veluwe/zandgrond | Lokale expert-positie |
| **grasengroenwinkel.nl** | Beperkte blog/kennisbank | Uitgebreide content hub |

### 6.3 Strategische Kansen

1. **"Complete gazon-shop" positionering** — Geen concurrent biedt graszaad + bemesting + haspels + gereedschap in één shop. Dit is een USP.

2. **Graszaad per bodemtype** — Vrijwel geen webshop biedt specifieke filtering/pagina's op bodemtype. Dit is een enorme SEO-kans.

3. **Seizoenscontent dominantie** — "Wanneer graszaad zaaien" en "gazon bemesten" artikelen trekken duizenden bezoekers per maand. Met goede content kun je hierop ranken.

4. **Keuzehulp/configurator** — Bouw een interactieve "Welk graszaad past bij mijn tuin?" tool. Dit genereert backlinks, engagement en conversies.

5. **B2B sportvelden** — De markt voor sportveld graszaad is minder competitief online. Richt je ook op sportverenigingen, gemeenten en hoveniers.
